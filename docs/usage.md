# 첨탑 코치

Slay the Spire 2 싱글플레이에서 현재 가능한 행동에 대한 AlphaDefect의 선호도를 보여 줍니다. 전투, 길찾기, 이벤트, 카드 보상, 포션 보상, 상점, 모닥불에서의 선택을 비교합니다. 플레이어가 직접 조작합니다.

## 설치와 사용

Windows x64와 Linux x64는 같은 창작마당 항목을 구독하면 됩니다. Linux용 추론 엔진은 v0.3.0부터 포함되어 있습니다. Steam Deck 실기 검증은 아직 진행 전입니다. 게임 모드 메뉴에서 활성화한 뒤 재시작하세요. 정규판 v0.111.1과 베타판 v0.113.1, v0.114.0에 맞춰 자동으로 전환합니다. ZIP으로 설치할 때는 `SpireCoach` 폴더를 게임 설치 폴더의 `mods` 안에 넣으세요.

- 첫 실행에 **모델 어휘 받기**를 탭하거나 **F7**을 누르세요. AlphaDefect 원본 저장소에서 파일 2개를 받아 SHA-256을 확인합니다. 이후에는 오프라인으로 쓸 수 있습니다.
- v0.114.0에서는 여섯 캐릭터의 공개 가중치를 해당 버전의 카드 데이터와 어휘에 맞춘 모델로 실행합니다. **F10**에서 `코치 설정 · v0.114.0`을, 첫 추천 후에는 사용 중인 가중치 파일명도 확인할 수 있습니다. 풀의 Optimism은 손에 든 Sadness 수를 반영하고, Twin Shot은 기존 Rapid Shot의 모델 ID를 이어받습니다. [AlphaDefect의 v0.114.0 적용 내역](https://github.com/hmty-CHEN/AlphaDefect-Public/tree/f77831b6ea77b8ece32daf1912154ae081da875c/game-v0.114.0)
- **F8** 또는 **R3**으로 추천 창을, **F6**으로 상세 설명을 켜거나 끕니다. 키를 바꾸려면 추천 카드의 **설정**, 메인 메뉴의 **코치 설정** 또는 **F10**을 여세요. 키보드와 패드 입력을 각각 지정할 수 있습니다. **F9** 또는 카드의 페이지 버튼으로 다음 추천을 봅니다.
- Steam Deck에서는 터치만으로 설정, 숨기기와 다시 열기, 페이지 이동까지 가능합니다. Steam Input 레이아웃에서 패드 버튼이 게임에 직접 전달되지 않으면 후면 버튼에 원하는 키보드 단축키를 할당하세요.
- 전투에서는 같은 상태의 카드를 같은 대상에게 쓰는 선택을 한 줄로 묶고 선호도를 합산합니다. 예를 들어 손에 흐릿함 한 장과 흐릿함+ 두 장이 있으면, 강화판 두 장의 선호도를 합쳐 일반판과 비교합니다. F10의 **전투 정렬**에서 한 장 기준으로 바꿀 수 있습니다.
- 카드 번호는 기본으로 켜져 있습니다. `손패 3번`은 실제 손패 왼쪽에서 세 번째 카드입니다. 보상과 카드 선택 화면은 화면에 놓인 순서를 따릅니다. F10의 **카드 번호 끄기**로 숨길 수 있습니다. 같은 카드의 현재 비용이 다르면 코스트와 별 비용을 표시합니다. 한 장에만 이번 턴 보존이나 교활 같은 효과가 붙으면 별도로 표시합니다.
- **AlphaDefect 탐색**은 기본으로 켜져 있습니다. 사일런트, 리젠트, 디펙트는 3막 보스에서 같은 무작위 조건으로 후보들을 비교합니다. v0.114.0에서도 롤아웃은 원본 v0.111.0 시뮬레이터를 사용하므로 이후 변경된 전투 규칙은 시뮬레이션 결과에 차이가 날 수 있습니다. 아이언클래드, 네크로바인더, 풀은 일반 전투, 정예, 보스에서 정보 집합 트리 탐색을 사용합니다. 첫 추천은 즉시 표시하고, 탐색이 끝나면 실제 추천 카드와 시뮬레이션 횟수를 한 줄 더 보여 줍니다. 백분율은 모델의 행동 선호도입니다.
- **F10 → 논문 설정 (가장 느림)**의 제한 시간은 롤아웃 4초, 트리 탐색 30초입니다. 200, 350, 500ms로 줄일 수 있습니다. 전투 상태가 달라지거나 제한 시간 안에 계산이 끝나지 않으면 기본 추천을 표시합니다. 구버전 시뮬레이터가 현재 보스, 손패, 적 상태를 재현할 수 없는 경우에도 기본 추천을 표시합니다.
- 실시간 모드는 게임 리플레이의 행동 카운터에서 탐색 시드를 정합니다. 원본이 같은 행동으로 묶는 카드 사본에 서로 다른 보존, 소멸 등 효과가 있으면 그 차이를 구분합니다. [롤아웃 원본](https://github.com/hmty-CHEN/AlphaDefect-Public/blob/800db3039162647bf0ad13ed379f155cc5806f5f/game-v0.111.0/tools/sim_pimc.py), [트리 탐색 원본](https://github.com/hmty-CHEN/AlphaDefect-Public/blob/800db3039162647bf0ad13ed379f155cc5806f5f/python/sts2rl/tree_live.py)
- 모닥불이나 이벤트에서 강화할 카드를 고를 때도 한 장당 선호도를 비교합니다. 현재 상태와 강화 결과가 같은 카드는 한 줄에 표시합니다.
- 전투 창의 예상 체력 손실은 해당 행동 직후 턴을 끝낸다는 가정의 추정치입니다. 카드 보상은 카드와 대체 선택지의 선호도를 표시합니다.
- 지도에서 이동할 차례가 되면 갈 수 있는 다음 방을 왼쪽부터 구분해서 보여 줍니다. 전투 중에 지도를 잠깐 열어 보면 추천은 숨깁니다.
- **F10 → 추천을 볼 단계**에서 전투, 길찾기, 이벤트, 카드 선택, 포션 보상, 상점, 모닥불을 개별로 체크하세요. 새로 설치하면 모두 켜져 있습니다. **카드 선택**은 카드 보상, 덱의 강화·제거·변환·인챈트, 손패의 버리기·강화·소멸, 카드 더미에서 가져오기, 생성된 카드 중 고르기에 적용됩니다. 여러 장을 고를 때는 한 장 고를 때마다 남은 카드의 선호도를 다시 계산합니다.
- **포션 보상**에서는 슬롯이 꽉 차면 버릴 포션의 이름과 슬롯 번호, 새 포션을 두고 가는 선택을 비교합니다. 다른 보상도 남아 있으면 함께 표시하고, 슬롯을 비우면 새 포션을 받는 선택이 뜹니다.
- **모닥불**에서는 휴식, 재련, 유물로 추가된 행동의 선호도를 표시합니다. 체력이 가득 찼고 휴식의 추가 효과가 없으면 재련이 가능할 때 휴식은 추천에서 빠집니다. 재련을 누르면 **카드 선택** 설정에 따라 강화할 카드별 추천이 뜹니다.
- 이벤트에서는 현재 페이지의 선택 가능한 버튼을 비교합니다. 고대의 존재는 대화가 끝나고 보상을 고를 때 유물 이름과 선호도가 표시됩니다. 두 화면 모두 설정의 **이벤트** 체크를 따릅니다.
- 상점에서 진열대를 열면 현재 골드와 포션 빈칸에 맞춰 상품 구매, 카드 제거, 나가기를 비교합니다. 물건을 사면 남은 골드와 재고로 다시 계산합니다.
- 정규판은 아이언클래드, 사일런트, 디펙트, 리젠트, 네크로바인더를 지원합니다. 풀이 추가된 베타판에서는 풀도 지원합니다.
- 정규판의 아이언클래드와 네크로바인더는 정규판 관측값에 손패 발광 여부와 즉각 에너지·드로우 획득 정보를 보강해 모델에 전달합니다.

## 크레딧

AlphaDefect 논문을 쓰신 Qiyue Chen, Taian Yu, Junpei Komiyama, Haobo Huang 님께 감사드립니다. 원본 가중치의 행동 선호도와 가치 평가를 ONNX로 실행합니다. 롤아웃에서는 iRyougi와 기여자들이 공개한 sts2-sim에 논문 저자들의 패치를 적용하고, 현재 게임에서 이미 만난 적과 눈앞의 보스를 불러오는 부분을 맞췄습니다. Slay the Spire 2는 Mega Crit의 게임입니다. [AlphaDefect GitHub](https://github.com/hmty-CHEN/AlphaDefect-Public), [논문](https://arxiv.org/abs/2611.31076), [sts2-sim GitHub](https://github.com/iRyougi/sts2-sim)

AlphaDefect의 MIT 라이선스와 예외 고지, 롤아웃 시뮬레이터 sts2-sim의 MIT 라이선스, ONNX Runtime과 .NET 라이브러리 고지는 `licenses` 폴더에 포함되어 있습니다. 게임 데이터에서 유래한 어휘 파일은 원본에서 별도로 받습니다. 게임 파일은 포함하지 않습니다.
